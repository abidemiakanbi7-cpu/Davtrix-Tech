# DAVTRIX Technologies — Website Starter

A responsive multi-section company website built with **HTML5, CSS3, and vanilla JavaScript**. No frameworks, build tools, or external libraries are required.

## What's included
- `index.html` — homepage, services, about, values, portfolio, process, contact, footer
- `css/styles.css` — brand styles, responsive layouts, accessibility focus states, reduced-motion support
- `js/main.js` — mobile navigation, current year, client-side enquiry form draft
- `assets/logo.svg` and `assets/favicon.svg` — editable vector brand marks

## Run it
1. Extract the ZIP.
2. Open the `DAVTRIX-Technologies-Website` folder in VS Code.
3. Open `index.html` in your browser. You can double-click the file; no terminal or internet is required.
4. If you later install a local preview extension, you can use that too, but it is optional.

## Before publishing
1. In `js/main.js`, replace `REPLACE_WITH_YOUR_REAL_EMAIL@example.com` with an email address you have created and tested. The form currently opens the visitor's email app; it does **not** send or save submissions on its own.
2. Replace the social links in the footer (`href="#"`) with your actual profiles after creating them.
3. Review the portfolio cards. They are illustrative descriptions, not proof of current project functionality. Add real screenshots and verified project links.
4. Confirm pricing, availability, and service descriptions before accepting a client.
5. If you need a real submission form, customer accounts, bookings, or payments, add a secure backend or trusted form service. This static site does not provide those features.
6. Check the phone links, spelling, mobile layout, and all links on your own devices.
